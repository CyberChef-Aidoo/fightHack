## 📥 Installation

```bash
Installing tcpdump

Tcpdump is pre-installed on most penetration-testing distributions, including Kali Linux. On a
general-purpose distribution such as Ubuntu, it usually needs a quick manual install.

4.1 On Kali Linux

Confirm it is already present:
tcpdump --version

If it is missing for any reason:
sudo apt update && sudo apt install tcpdump

4.2 On Ubuntu

Step 1- Update package lists
sudo apt update

Step 2- Install tcpdump
sudo apt install tcpdump -y

Step 3- Verify the installation
tcpdump --version

Expected output looks like this:
tcpdump version 4.99.6
libpcap version 1.10.6 (64-bit time_t, with TPACKET_V3)
OpenSSL 3.5.5
64-bit build, 64-bit time_t

Setting up a lab pair. For several practicals in this book, it helps to have a second machine
or virtual machine with no DNS service running - a clean stand-in for a "broken" server.
```
